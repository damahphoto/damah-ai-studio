배경

배경을 업로드하거나 기본 색상을 선택하세요.

배경 사진 배치

배경 사진을 추가한 뒤 확대·위치를 조절하세요. 원본 인물은 변경하지 않습니다.

AI 배경 생성 v0.5 서버 연결

안전한 서버가 연결되면 생성 기능을 사용할 수 있어요. 공개 웹페이지에 API 키를 넣지 않습니다.

AI 배경 생성 시 설명 문구만 서버로 전송합니다. 인물 사진은 전송하지 않습니다. 서버 배포와 API 요금 설정이 필요합니다.

인물 분리

배경 제거가 정확하지 않으면 붓으로 수정하세요. 브러시로 지우기·복원할 수 있고, 부드러운 가장자리도 조절할 수 있어요.

배경을 교체하려면 먼저 인물을 분리해야 합니다. 단색 빠른 분리에서 얼굴이 사라질 위험이 감지되면 자동으로 취소됩니다. 흰색/그레이 등 단색 배경은 단색 배경 빠른 분리(제한적)를, 인물과 배경의 색이 비슷하거나 복잡한 사진은 자동 배경 분리(베타)를 사용하세요.

⚠ 얼굴 보호는 원본 사진을 AI로 재생성하지 않는 구조입니다. 조명 효과는 픽셀 밝기·색을 변경할 수 있습니다.

조명 실험실

34가지 조명 코드에서 선택하세요. 일부는 1차 버전의 근사 효과이며 실제 3차원 재조명은 아닙니다.

켜면 인물의 원래 색·밝기를 유지합니다. 끄면 인물에도 조명 색·밝기 효과가 적용됩니다. 실제 광학적 재조명은 아닙니다.

접지 그림자

분리된 인물의 형태에서 그림자를 계산해 바닥에 투영합니다. 광원과 배경에 따라 직접 조절하세요.

내보내기

원본 사진을 불러오면 픽셀 크기를 확인할 수 있어요.

원본 보존 정책

작업 미리보기는 화면에 맞게 축소되지만, 저장할 때 원본 가로·세로 픽셀 크기를 사용합니다. 매우 큰 사진은 기기의 메모리·캔버스 한계 때문에 저장되지 않을 수 있습니다.
